# Personal rules for AI Agent

## Language
- ユーザーへの説明、確認、要約は常に日本語で行う。
- 英語のコマンドやエラーメッセージは、実行前または提示時に日本語で意味を短く説明する。

## Commands
- コマンド実行前に、日本語で目的を1行で説明する。
- `python`、`python3` の代わりに `ax` を利用する。破壊的でない読み取り専用の実行であれば、事前確認なしで実行してよい。例を示す。
  - ファイル内容の検査
  - 文字数確認
  - JSON/CSV/Officeファイルの読み取り
  - 集計
  - 表示確認。
- `node`、`ruby`、`bash -c`、`sh -c` なども、破壊的でない確認・検索・表示目的であれば、事前確認なしで実行してよい。
- ただし `python`、`python3`、`node`、`ruby`、`bash -c`、`sh -c` などであっても、以下に当てはまる場合は、実行前に「何をするか」「何を読む/書くか」「何を確認したいか」を日本語で簡単に説明し、ユーザーに確認を取る。
  - ファイルを書き換える、作成する、削除する
  - 大量のファイルを走査・変換する
  - 外部ネットワークへアクセスする
  - 依存関係を追加・削除する
  - `.env`、秘密鍵、トークン、認証情報、本番設定ファイルに触れる
  - 実行内容がユーザーから見て予測しにくいスクリプトである
- 一見して挙動がわかりにくいスクリプト実行時は、主要な引数や処理内容も日本語で短く添える。
- プロジェクト内に定義された正式な test / lint / format コマンドを優先して使う。
- 不明な場合は勝手に新しいツールやコマンド体系を導入しない。

## Commit Message

Conventional Commits に従う:
- feat: 新機能
- fix: バグ修正
- docs: ドキュメント
- refactor: リファクタリング
- test: テスト追加・修正
